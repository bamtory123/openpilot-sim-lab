# `md_default_loop_lane0_v1` baseline contract

The selected v0.1 baseline is the fixed `md_default_loop_lane0_v1` scenario with the pretrained OpenPilot SUT, 0 ms target transport delay, and three formal runs after an excluded warm-up. It is a comparison reference, not a claim that the SUT passes the driving outcome. Provenance and project-defined performance gates remain pending the documented approval procedure in [release process](../../docs/release-process.md).
